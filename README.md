# Space Quiz

Space Quiz is a polished, dependency-free space exploration quiz built as a single `index.html` file. It includes ten questions, progress tracking, animated correct and incorrect feedback, mission-control styling, light and dark themes, and a locally stored best score.

## Run locally

No server or package installation is required. Open [`index.html`](./index.html) directly in a modern browser.

For local development in VS Code:

1. Open the project folder.
2. Open `index.html` in the integrated browser, or use the file explorer to open it in a browser.
3. Edit the file and reload the page to see changes.

## Deploy

The repository includes a GitHub Actions workflow that publishes the site to GitHub Pages whenever changes are pushed to `main`.
